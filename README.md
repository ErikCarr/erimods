# Modrik

O launcher de mods de Among Us do Erik Carr: perfis de mods, loja de mods e o jogo original intocado.

**Baixar:** https://erikcarr.github.io/modrik/ (ou a versão mais nova em [Releases](https://github.com/ErikCarr/modrik/releases/latest)).

Este repositório guarda só as versões publicadas do Modrik (o `.exe` em cada Release), a página de download e o
`atualizacao.json`, que o Modrik lê para avisar quando tem versão nova. O código fica em outro lugar.

## Como usar

1. Abra o `Modrik-v….exe`. Se o Windows avisar "O Windows protegeu o computador", clique em **Mais informações** →
   **Executar assim mesmo**.
2. Clique em **Instalar**: o Modrik vai para a pasta de programas do seu usuário, com atalhos, e acha o Among Us sozinho.
3. Crie um perfil, adicione mods ou pegue da aba **Loja**, e clique em **JOGAR**.

Para desinstalar: **Aplicativos instalados** do Windows → Modrik → Desinstalar. Os perfis e mods ficam em
`%AppData%\Modrik`.
